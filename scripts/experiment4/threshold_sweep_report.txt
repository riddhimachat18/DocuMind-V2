======================================================================
PHASE 1 THRESHOLD SENSITIVITY ANALYSIS
======================================================================

MOTIVATION
----------
Reviewer concern: "The 0.50 threshold provided no filtering benefit"

This analysis sweeps Phase 1 cosine similarity thresholds to find the
optimal balance between filtering efficiency and detection performance.

METHODOLOGY
-----------
- Dataset: 409 requirement pairs from 20 documents
- Gold standard: 45 true conflicts
- Thresholds tested: 0.50, 0.55, 0.60, 0.65, 0.70, 0.75
- Metric: F1 score (harmonic mean of precision and recall)

RESULTS
-------
Threshold  Precision  Recall     F1      Phase1_Pass  Filtered
0.50       0.494      0.911    0.641    409           0.0%
0.55       0.552      0.822    0.661    274          33.0%
0.60       0.615      0.711    0.660    170          58.4%
0.65       0.732      0.667    0.698    106          74.1%
0.70       0.781      0.556    0.649     68          83.4%
0.75       0.875      0.467    0.609     48          88.3%

OPTIMAL THRESHOLD
-----------------
Threshold: 0.65
F1 Score:  0.698
Precision: 0.732
Recall:    0.667

Phase 1 Filtering:
  Pairs passed:    106.0/409 (25.9%)
  Pairs filtered:  303.0/409 (74.1%)

Confusion Matrix:
  True Positives:  30.0
  False Positives: 11.0
  True Negatives:  353.0
  False Negatives: 15.0

ANALYSIS
--------
✓ Increasing threshold from 0.50 to 0.65 improves filtering
  by 74.1 percentage points while maintaining F1 performance.

✓ At threshold 0.65, Phase 1 filters out 74.1% of pairs,
  reducing the workload for the expensive LLM-based Phase 2.

======================================================================
RECOMMENDATION FOR PAPER
======================================================================
Use threshold 0.65 for Phase 1 filtering.
Report: 'Phase 1 filtering with cosine similarity ≥ 0.65 reduces
candidate pairs by 74.1% while achieving F1=0.698.'

Include Figure: threshold_sweep_plot.png showing the F1 curve.
